# Calculadora Web

Calculadora simples feita com HTML, CSS e JavaScript puro.

## 🚀 Tecnologias
- HTML5
- CSS3
- JavaScript (lógica de cálculo)
- Git / GitHub Pages

## ▶️ Como rodar
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
